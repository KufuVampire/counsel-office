# Приём заявок в Google Таблицу

Форма на сайте отправляет заявку POST-запросом в веб-приложение Google Apps Script
(`Code.gs`), которое добавляет строку на лист «Заявки».

## Развёртывание

1. Создать Google Таблицу, открыть **Расширения → Apps Script**.
2. Заменить содержимое `Code.gs` кодом из этой папки и сохранить.
3. **Развернуть → Новое развёртывание** → тип **Веб-приложение**:
   - «Выполнять от имени»: **Я**;
   - «У кого есть доступ»: **Все**.
4. Подтвердить доступ к таблице и скопировать URL вида
   `https://script.google.com/macros/s/.../exec`.
5. Указать URL в переменной `VITE_CONSULTATION_ENDPOINT` (Vercel → Settings →
   Environment Variables) или в `src/shared/config/site.ts`.

После правки `Code.gs` нужно обновить существующее развёртывание
(**Управление развёртываниями → Изменить → Новая версия**), иначе URL продолжит
отдавать старую версию.

## Что проверяет скрипт

- имя от 2 символов, телефон от 10 цифр, известный способ связи;
- длина полей ограничена, значения, начинающиеся с `=`, `+`, `-`, `@`, сохраняются
  как текст, чтобы таблица не выполнила их как формулу;
- запись идёт под `LockService`, поэтому одновременные заявки не перезаписывают друг друга.

Без `VITE_CONSULTATION_ENDPOINT` в режиме разработки форма имитирует отправку и
пишет предупреждение в консоль, в продакшн-сборке показывает ошибку.
